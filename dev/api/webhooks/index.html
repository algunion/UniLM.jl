Reference · API: OpenAI platform

Webhooks API

Verify inbound webhook signatures (Standard Webhooks / HMAC-SHA256) and parse events into typed values — an inbound utility with no provider endpoint, its HMAC built on the SHA standard library —, and manage a project's webhook endpoints at OpenAI (the :webhooks capability). OpenAI webhooks.

Types and Constants

UniLM.WebhookEventType#
WebhookEvent

A parsed webhook event from parse_webhook: id, type, and created_at; data holds the event payload and raw the unparsed JSON response.

UniLM.WEBHOOK_EVENTSConstant#

The event types of OpenAI's webhooks (reference): background responses, batches and fine-tuning jobs that end, incoming SIP calls for the Realtime and Live APIs, a Live session that connects (live.transport.connected, "Sent when a direct Live WebRTC session is created or an Instant Connect session activates"), safety warnings and deactivations for a safety identifier, safety alerts, and the agent sessions of OpenAI's Agents API and the environments they run in (agent.session.*, agent.environment.*, which OpenAI's API specification lists). live.call.incoming is deprecated in favour of live.transport.incoming and retained for existing subscriptions. The reference also lists eval.run.succeeded, eval.run.failed and eval.run.canceled, which OpenAI sends until its Evals API shuts down on November 30, 2026 (deprecations), and OpenAI's list of event types (list_webhook_event_types, November 16, 2026) still names video.completed and video.failed, the events of its Videos API, which shut down on September 24, 2026: they are all left out, so a filter on this list drops them.

UniLM.WebhookEndpointType#
WebhookEndpoint

A project's webhook endpoint: its id, name, url, the event_types it receives, created_at and updated_at (Unix seconds; updated_at moves with a change of its configuration or secret), the masked signing_secret_hint, and the signing_secret itself, which OpenAI returns only from create_webhook_endpoint and rotate_webhook_endpoint_secret (nothing otherwise): keep it for verify_webhook. raw holds the reply. A printed endpoint shows the secret as <not shown> and leaves raw out.

UniLM.WebhookEndpointListType#

A page of WebhookEndpoints from list_webhook_endpoints; has_more signals further pages, raw holds the reply (first_id, last_id) and is left out when the page is printed.

UniLM.WebhookEndpointTestType#

The sample delivery of test_webhook_endpoint: the event_type sent to the endpoint webhook_endpoint_id, and the HTTP status_code the endpoint answered with.

Functions

UniLM.verify_webhookFunction#
verify_webhook(payload::AbstractString, headers, secret::AbstractString; tolerance_seconds=300) -> Bool

Verify an OpenAI webhook signature (Standard Webhooks). payload is the raw request body; headers is a Dict or iterable of pairs containing webhook-id, webhook-timestamp, and webhook-signature; secret is the endpoint signing secret, with or without the whsec_ prefix: without it, the secret is read as base64 too, as the Standard Webhooks libraries read it (OpenAI's SDKs take an unprefixed secret's raw bytes as the key). Returns true iff a fresh, validly-signed v1 signature is present.

Replay protection: timestamps outside ±tolerance_seconds of now are rejected, as are timestamps that are not finite numbers — pass tolerance_seconds=Inf to skip the time check (e.g. when replaying a stored fixture). Uses a constant-time digest compare. Negative or NaN tolerances throw ArgumentError.

Whitespace around secret is ignored. Throws ArgumentError before any check when the rest is empty ("", whitespace, or whsec_ alone): anyone can sign with an empty key, so under one a forged delivery would verify. Throws ArgumentError when the rest is not valid base64 — a character outside A-Z, a-z, 0-9, + and / (whitespace inside it included), or = padding anywhere but at its end or more than its last group lacks — for a delivery that reaches the signature check: that is a misconfiguration of this endpoint, and reporting it as an unverified signature would silently drop every webhook. A false return therefore always means the message failed verification.

UniLM.parse_webhookFunction#
parse_webhook(payload::AbstractString) -> WebhookEvent

Parse a webhook JSON payload into a typed WebhookEvent. Verify the signature with verify_webhook first.

Endpoint management

UniLM.create_webhook_endpointFunction#
create_webhook_endpoint(; name, url, event_types, service=OPENAIServiceEndpoint)

Make a webhook endpoint for the project: OpenAI delivers the event_types (see list_webhook_event_types) to the HTTPS url. The result's endpoint holds its signing_secret, which OpenAI returns only here and from rotate_webhook_endpoint_secret; a reply without one is the WebhookEndpointCallError.

Every Webhook endpoints verb needs the :webhooks capability, makes one attempt bounded by its config, and takes cancel: a cancelled token returns a WebhookEndpointCallError whose cause is a UniLMCancelled, without sending anything when it was cancelled before the call.

UniLM.list_webhook_endpointsFunction#
list_webhook_endpoints(; limit=nothing, after=nothing, service=OPENAIServiceEndpoint)

The project's webhook endpoints, newest first, a page at a time: limit (1 to 100; OpenAI's default 20) and after, the last id of the previous page. A reply without data or has_more is the WebhookEndpointCallError.

UniLM.retrieve_webhook_endpointFunction#
retrieve_webhook_endpoint(id; service=OPENAIServiceEndpoint)

The webhook endpoint id, without its signing secret.

UniLM.update_webhook_endpointFunction#
update_webhook_endpoint(id; name=nothing, url=nothing, event_types=nothing, service=OPENAIServiceEndpoint)

Change the webhook endpoint id: each of name, url and event_types (the complete new set) that is given; the rest stay. The result holds the endpoint without its signing secret.

UniLM.delete_webhook_endpointFunction#
delete_webhook_endpoint(id; service=OPENAIServiceEndpoint)

Delete the webhook endpoint id: a WebhookEndpointDeleteSuccess when OpenAI's record names the endpoint, is a "webhook_endpoint.deleted" object and says "deleted": true, the WebhookEndpointCallError otherwise.

UniLM.rotate_webhook_endpoint_secretFunction#
rotate_webhook_endpoint_secret(id; keep_old_secret_active_for_24_hours=nothing, service=OPENAIServiceEndpoint)

Give the webhook endpoint id a new signing secret, held by the result's endpoint. The previous secret stops verifying at once, unless keep_old_secret_active_for_24_hours=true keeps it valid for 24 hours.

UniLM.test_webhook_endpointFunction#
test_webhook_endpoint(id, event_type; service=OPENAIServiceEndpoint)

Send a sample event_type delivery to the webhook endpoint id: a WebhookTestSuccess holding the HTTP status code the endpoint answered with. OpenAI's 500 says the sample could not be sent, a WebhookEndpointFailure.

UniLM.list_webhook_event_typesFunction#
list_webhook_event_types(; service=OPENAIServiceEndpoint)

The event types the project may subscribe a webhook endpoint to, as a WebhookEventTypesSuccess.

Result Types

UniLM.WebhookEndpointSuccessType#

Successful create, retrieve, update or secret rotation result wrapping a WebhookEndpoint.

UniLM.WebhookEndpointListSuccessType#

Successful list_webhook_endpoints result wrapping a WebhookEndpointList.

UniLM.WebhookEndpointDeleteSuccessType#

Successful delete_webhook_endpoint result: the service confirmed (deleted is always true) the removal of id.

UniLM.WebhookTestSuccessType#

Successful test_webhook_endpoint result wrapping a WebhookEndpointTest.

UniLM.WebhookEventTypesSuccessType#

Successful list_webhook_event_types result: the event_types the project may subscribe to.

UniLM.WebhookEndpointFailureType#

Webhook endpoints API error result: HTTP status, the raw response body, and the request_id the service sent (x-request-id/request-id header), if any.

UniLM.WebhookEndpointCallErrorType#

Webhook endpoints API call that produced no usable reply (transport failure, timeout, or a 200 that could not be decoded); cause is the underlying exception — a UniLMTimeout for a timeout.

Usage 

# Verify an inbound webhook, then parse it into a typed event
if verify_webhook(payload, headers, ENV["OPENAI_WEBHOOK_SECRET"])
    event = parse_webhook(payload)
    event.type in WEBHOOK_EVENTS && println("Event: ", event.type, " (", event.id, ")")   # no eval.run.* or video.*
end

# Make an endpoint, keep its signing secret, send it a sample event, then delete it
made = create_webhook_endpoint(name="batches", url="https://example.com/openai-webhooks",
                               event_types=["batch.completed", "batch.failed"])
made isa WebhookEndpointSuccess || error("the endpoint was not made: $made")
secret = made.response.signing_secret             # returned only here and by rotate_webhook_endpoint_secret
test_webhook_endpoint(made.response.id, "batch.completed")   # WebhookTestSuccess: response.status_code
delete_webhook_endpoint(made.response.id)

WEBHOOK_EVENTS leaves out the eval.run.* events, which OpenAI sends until its Evals API shuts down on November 30, 2026, and video.completed and video.failed, the events of its Videos API, which shut down on September 24, 2026 (deprecations), though list_webhook_event_types still returned them on November 16, 2026: the filter above drops them, so match event.type yourself if you still run evals or receive video events.
