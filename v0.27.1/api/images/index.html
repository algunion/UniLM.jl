Image Generation API

Types and functions for generating and editing images: OpenAI's Images API (/v1/images/generations, /v1/images/edits) and Gemini's native image generation (Nano Banana) through generateContent, chosen by the request's service.

Request Type

UniLM.ImageGenerationType#
ImageGeneration(; prompt, service=OPENAIServiceEndpoint, model="", kwargs...)

An image-generation request for generate_image. It goes to OpenAI's Images API (/v1/images/generations), or, with service=GEMINIServiceEndpoint, to Gemini's generateContent with image output (Nano Banana). Each field below says which provider takes it.

Fields — both providers

  • service: OPENAIServiceEndpoint (default) or GEMINIServiceEndpoint; any other endpoint is sent the OpenAI Images API request.
  • model::String: The default is the sentinel "", which resolves at serialization time to the service's default image model ("gpt-image-2.5-sunburst" for OpenAI, "gemini-nano-banana-2.1" for Gemini) — so the field READS BACK as "" until you set it explicitly, and a service with no default image model throws ArgumentError when the request is serialized. Inspect JSON.json(ig) to see the body that will go on the wire; Gemini names the model in the URL instead.
  • prompt::String: A text description of the desired image
  • n::Union{Int,Nothing}: Number of images to generate: 1–10 on OpenAI; Gemini returns one image per request, so it takes only 1
  • safety_identifier::Union{String,Nothing}: A stable identifier for your end user (hash a username or email address), for the provider's abuse monitoring. OpenAI takes 1 to 128 characters (safety identifiers); Gemini sends it as the request label safety_identifier, which allows at most 63 lowercase letters, numerals, underscores and dashes, international ones included.

Fields — OpenAI only

  • size::Union{String,Nothing}: Size ("1024x1024", "1536x1024", "1024x1536", "auto"). On gpt-image-2 and later, any WIDTHxHEIGHT with both edges multiples of 16, up to 3840x2160 (aspect ratio between 1:3 and 3:1)
  • quality::Union{String,Nothing}: Quality level ("low", "medium", "high", "auto"); gpt-image-2.5-flare and gpt-image-2.5-sunburst also accept "xhigh" and "max"
  • background::Union{String,Nothing}: Background ("transparent", "opaque", "auto")
  • output_format::Union{String,Nothing}: File format ("png", "webp", "jpeg")
  • output_compression::Union{Int,Nothing}: Compression (0–100, for "webp" and "jpeg")
  • moderation::Union{String,Nothing}: Content-moderation strictness ("auto", "low")

Fields — Gemini only

Gemini's image controls:

  • aspect_ratio::Union{String,Nothing}: "1:1", "1:4", "4:1", "1:8", "8:1", "2:3", "3:2", "3:4", "4:3", "4:5", "5:4", "9:16", "16:9" or "21:9"; unset, the image is square
  • resolution::Union{String,Nothing}: "512", "1K", "2K" or "4K"; unset, "1K". gemini-nano-banana-2.1 renders at "1K", "2K" or "4K".

A field the request's provider does not take (an OpenAI-only field on Gemini; aspect_ratio or resolution on OpenAI), n other than 1 on Gemini, a Gemini aspect_ratio or resolution outside the lists above, and a safety_identifier outside its provider's rule throw ArgumentError naming the provider and the field — when the request is serialized, and in generate_image before any request. Other OpenAI values are sent as given, for OpenAI to judge. input_fidelity is an image-edit parameter: set it on ImageEdit, not here.

Examples

# Simple prompt
ImageGeneration(prompt="A watercolor painting of a mountain sunset")

# With all options
ImageGeneration(
    prompt="A minimalist logo for a Julia package",
    size="1024x1024",
    quality="high",
    background="transparent",
    output_format="png"
)

# Gemini, wide and at 2K
ImageGeneration(service=GEMINIServiceEndpoint, prompt="A lighthouse at dusk",
                aspect_ratio="16:9", resolution="2K")
UniLM.ImageEditType#
ImageEdit(; image, prompt, service=OPENAIServiceEndpoint, model="", kwargs...)

An image-edit request for edit_image: the image(s) at image (a path, or a vector of paths) changed as prompt asks. OpenAI is sent multipart/form-data at /v1/images/edits; GEMINIServiceEndpoint is sent generateContent with each image as an inline part ahead of the prompt, its format read from the file's bytes (PNG, JPEG, GIF or WebP). model left "" is the service's default image model ("gpt-image-2.5-sunburst" on OpenAI, "gemini-nano-banana-2.1" on Gemini), resolved when the edit is sent.

Fields — both providers

image and model (above); service, prompt, n and safety_identifier, as on ImageGeneration: Gemini takes n=1 only.

Fields — OpenAI only

  • mask::Union{String,Nothing}: path of a mask whose transparent area marks what to edit
  • size, quality, background, output_format: as on ImageGeneration
  • input_fidelity::Union{String,Nothing}: how closely the edit keeps the input's features ("high", "low")

Fields — Gemini only

aspect_ratio and resolution, as on ImageGeneration; unset, the edited image follows the input's aspect ratio.

image names at least one file: edit_image throws ArgumentError for an empty vector before any request, as it does, naming the provider and the field, for a field the request's provider does not take, n other than 1 on Gemini, a Gemini aspect_ratio or resolution outside its list, and a safety_identifier outside its provider's rule. Other OpenAI values are sent as given, for OpenAI to judge.

Construction 

using UniLM
using JSON

# Minimal request. `model` is a sentinel: it stays "" on the struct and resolves
# only when the request is serialized, so read the wire body to see what will be
# sent rather than the field.
ig = ImageGeneration(prompt="A watercolor painting of a sunset")
println("Model field: ", repr(ig.model))
println("Model on the wire: ", JSON.parse(JSON.json(ig))["model"])
println("Prompt: ", ig.prompt)

# Full options
ig2 = ImageGeneration(
    prompt="A minimalist logo for a Julia package",
    size="1024x1024",
    quality="high",
    background="transparent",
    output_format="png",
    n=2
)
println("\nFull options:")
println("  Size: ", ig2.size)
println("  Quality: ", ig2.quality)
println("  Background: ", ig2.background)
println("  Format: ", ig2.output_format)
println("  Count: ", ig2.n)

JSON Serialization 

ig = ImageGeneration(prompt="A cute robot", quality="high", size="1024x1024",
                     safety_identifier="user-7f3a")
println(JSON.json(ig))

A Gemini request serializes to its generateContent body; the model, gemini-nano-banana-2.1 unless set, goes in the URL:

gig = ImageGeneration(service=GEMINIServiceEndpoint, prompt="A lighthouse at dusk",
                      aspect_ratio="16:9", resolution="2K")
println(JSON.json(gig))

A field the other provider owns is refused before anything is sent:

try
    JSON.json(ImageGeneration(service=GEMINIServiceEndpoint, prompt="A lighthouse", quality="high"))
catch e
    println(e.msg)
end

Response Types

UniLM.ImageObjectType#
ImageObject

A single generated image from the API response.

Fields

  • b64_json::Union{String,Nothing}: Base64-encoded image data; Gemini sends JPEG (the mimeType of each image part in the response's raw says so)
  • revised_prompt::Union{String,Nothing}: The prompt as revised by the model; on Gemini, the text the model sent with the image (nothing when it sent none)
  • url::Union{String,Nothing}: Where to download the image, when the service delivered it by URL instead of inline
UniLM.ImageResponseType#
ImageResponse

Parsed response from the Image Generation API.

Accessors

  • image_data(r) — the image payloads: base64 data, or the URL of a URL-delivered image
  • r.created, r.data, r.usage — basic fields
  • r.raw — the complete raw JSON dict

Fields

  • created::Int64: Timestamp when the response was created; a Gemini reply carries none, so on Gemini it is the time the reply arrived (Unix seconds)
  • data::Vector{ImageObject}: Generated images
  • usage::Union{Dict{String,Any},Nothing}: Token usage information under the Images API's keys (input_tokens, output_tokens, total_tokens, and their details); Gemini's usageMetadata is mapped to them as on Gemini Chat, its thinking counted as output and as reasoning_tokens
  • raw::Dict{String,Any}: Complete raw JSON response

Result Types

UniLM.ImageSuccessType#
ImageSuccess <: LLMRequestResponse

Successful image generation. Access the parsed response via .response.

Examples

result = generate_image("A cute robot")
if result isa ImageSuccess
    imgs = image_data(result)   # Vector{String} of base64 images
    save_image(imgs[1], "robot.png")
end
UniLM.ImageFailureType#
ImageFailure <: LLMRequestResponse

HTTP-level failure from the Image Generation API: the raw response body, the status code, and the request_id the service sent (x-request-id/request-id header), if any.

UniLM.ImageCallErrorType#
ImageCallError <: LLMRequestResponse

Exception-level error during an Image Generation API call (network, timeout, or a 200 that could not be parsed — on Gemini, one that holds no image). cause is the underlying exception — a UniLMTimeout for a timeout — and request_id is set when a reply arrived but could not be decoded.

Request Function

UniLM.generate_imageFunction#
generate_image(ig::ImageGeneration; config=nothing, cancel=nothing)

Send an image-generation request: to OpenAI's Images API, or, for service=GEMINIServiceEndpoint, to Gemini's models/{model}:generateContent, asking for image output only and sizing the image by imageConfig when aspect_ratio or resolution is set (Gemini image generation).

Returns ImageSuccess, ImageFailure, or ImageCallError. A Gemini reply's image parts become its ImageObjects, in order, each carrying the text the model sent, if any, as revised_prompt; the interim images of the model's thinking are not among them. A Gemini 200 that holds no image is an ImageCallError naming Gemini's finish reason (such as IMAGE_SAFETY or NO_IMAGE).

Throws ArgumentError before any network I/O when ig.service is an endpoint type that declares its capabilities and does not list :images, and when the request sets a field its provider does not take, n other than 1 on Gemini, a Gemini aspect_ratio or resolution outside its list, or a safety_identifier outside its provider's rule (see ImageGeneration). Other OpenAI values are sent as given.

Examples

ig = ImageGeneration(prompt="A cute robot learning Julia", quality="high")
result = generate_image(ig)
if result isa ImageSuccess
    println("Generated $(length(result.response.data)) image(s)")
    save_image(image_data(result)[1], "robot.png")
end

Pass config::Union{Nothing,RequestConfig} to override the timeout/retry budget for this call.

Pass cancel::Union{Nothing,CancelToken} (default: the ambient with_cancel token) to make the call cancellable: once the token is cancelled it returns an ImageCallError whose cause is a UniLMCancelled — without sending anything when the token was already cancelled, at once when mid-request (never retried).

generate_image(prompt::String; kwargs...)

Convenience method: create an ImageGeneration from a prompt + keyword arguments and send it. config and cancel go to the request, as for generate_image(ig).

Examples

# Simple generation
result = generate_image("A watercolor painting of a Julia butterfly")

# With options
result = generate_image(
    "A minimalist logo",
    size="1024x1024",
    quality="high",
    background="transparent"
)

# Gemini
result = generate_image("A watercolor painting of a Julia butterfly";
                        service=GEMINIServiceEndpoint, aspect_ratio="3:2")

# Save to file
if result isa ImageSuccess
    save_image(image_data(result)[1], "logo.png")
end
UniLM.edit_imageFunction#
edit_image(e::ImageEdit; config=nothing, cancel=nothing) -> LLMRequestResponse
edit_image(image, prompt; mask=nothing, service=OPENAIServiceEndpoint, config=nothing, cancel=nothing, kwargs...)

Edit/extend image(s) under a text prompt — on OpenAI's Images API, or on Gemini's generateContent for service=GEMINIServiceEndpoint. Returns the same ImageSuccess/ImageFailure/ImageCallError shapes as generate_image, and a Gemini reply decodes the same way. An input image or mask that is not a readable file is an ImageCallError.

Throws ArgumentError before any network I/O when e.service declares its capabilities without :image_edits, when e.image is an empty vector, and when the request sets a field its provider does not take, n other than 1 on Gemini, a Gemini aspect_ratio or resolution outside its list, or a safety_identifier outside its provider's rule (see ImageEdit). Other OpenAI values are sent as given.

Pass config::Union{Nothing,RequestConfig} to override the timeout/retry budget for this call, and cancel::Union{Nothing,CancelToken} to make it cancellable exactly as for generate_image: a cancelled call returns an ImageCallError whose cause is a UniLMCancelled.

Usage Examples 

julia> result = generate_image(
           "A watercolor painting of a friendly robot reading a Julia programming book",
           size="1024x1024", quality="medium"
       )

julia> result isa ImageSuccess
true

julia> length(image_data(result))
1

julia> save_image(image_data(result)[1], "robot_julia.png")
"robot_julia.png"

Accessor Functions

UniLM.image_dataFunction#
image_data(r::ImageResponse)::Vector{String}
image_data(r::ImageSuccess)::Vector{String}

The image payloads of a response, one per generated image: the base64 data, or — for an image the service delivered by URL — its url (download it; only base64 data can go to save_image). An entry carrying neither is skipped.

On an ImageFailure or ImageCallError this throws an LLMResultError, as text does: a call that did not succeed has no images, and an empty list would read as "zero images generated".

Examples

result = generate_image("A sunset over mountains")
imgs = image_data(result)       # Vector{String}
length(imgs)                     # number of images generated
UniLM.save_imageFunction#
save_image(img_b64::String, filepath::String)

Decode a base64-encoded image and save it to a file.

Decoding happens before filepath is opened, so a malformed payload raises without touching whatever already lives there — a failed save costs nothing.

Examples

result = generate_image("A watercolor landscape")
if result isa ImageSuccess
    save_image(image_data(result)[1], "landscape.png")
end

Saving Images 

result = generate_image("A sunset over mountains", n=3)
if result isa ImageSuccess
    for (i, img) in enumerate(image_data(result))
        save_image(img, "sunset_$i.png")
    end
end
