Introduction

UniLM.jl

One Julia API for language models and decision models.

UniLM.jl gives Julia one set of types and verbs for two kinds of model. A language model writes: an answer, a call of one of your functions, JSON that fits a schema. A decision model reads a piece of state — a message, a record, a picture — and answers the questions you list about it with a probability for each answer you allowed, writing no text. Each kind has its chapter, and each provider an entry of its own: its setup, its first call, its options, limits and failures, on its own pages.

Language models

A Chat holds a conversation and chatrequest! sends it; respond sends one request of a provider's agentic API; embeddings, images, speech, transcription and fill-in-the-middle completion have verbs of their own, on the providers that serve them. Choose your provider below: its name opens its entry. Language models maps the concepts every provider shares.

Decisions

ask sends the questions — which of these options, where on this scale, whether this statement holds — and returns typed answers your code branches on, and nl_classify and nl_dispatch turn an answer into the key or the method that runs. One API across providers

The provider is one argument: service names its endpoint and model its model, so code written for one provider runs on another once those two change, as far as the other provider serves what the code asks: the same types and verbs, the same typed results, the same cost accounting and the same RequestConfig. One API across providers says what every provider shares, how to switch, and where the providers differ — which speak their own API and which the OpenAI-compatible one; Capabilities by provider shows what each provider serves; and Write your own backend adds a provider UniLM does not ship. For decision models, the same choice is Choosing a decision provider.

Install

UniLM requires Julia 1.13 or later and is registered in Julia's General registry:

using Pkg
Pkg.add("UniLM")

Install leads on to your provider's setup and its first call.
