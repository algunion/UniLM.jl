Reference · API: OpenAI platform

Vector Stores API

Create, update and search vector stores, and manage their files and file batches; the stores power the Responses file_search tool. Upload files via the Files API first. OpenAI only.

Objects

UniLM.VectorStoreObjectType#
VectorStoreObject

A vector store from the Vector Stores API: id, name, status, and file_counts; raw holds the unparsed JSON response.

UniLM.VectorStoreFileObjectType#
VectorStoreFileObject

A file attached to a vector store: id and status; raw holds the unparsed JSON response (its attributes, usage_bytes, last_error, …).

UniLM.VectorStoreFileBatchType#
VectorStoreFileBatch

A batch of files added to a vector store: id, status, and file_counts; raw holds the unparsed JSON response.

UniLM.VectorStoreListType#
VectorStoreList

A page of VectorStoreObjects from list_vector_stores; has_more signals that further pages are available.

UniLM.VectorStoreFileListType#
VectorStoreFileList

A page of VectorStoreFileObjects from list_vector_store_files or list_file_batch_files; has_more signals that further pages are available.

UniLM.VectorStoreFileContentType#
VectorStoreFileContent

The text OpenAI parsed from a vector store file, from vector_store_file_content: data, its parts as OpenAI sent them (each a Dict with "type" — "text", the one type OpenAI documents — and "text"), has_more, and next_page, the token of a further page (nothing when there is none); raw holds the unparsed JSON response.

UniLM.VectorStoreSearchPageType#
VectorStoreSearchPage

A page of VectorStoreSearchResults from search_vector_store: search_query, the queries searched (rewritten when rewrite_query asked for it), data, has_more, and next_page, the token of a further page (nothing when there is none); raw holds the unparsed JSON response.

UniLM.VectorStoreSearchResultType#
VectorStoreSearchResult

One file a search_vector_store found: file_id, filename, score (the similarity, 0 to 1), the file's attributes (nothing when it has none) and content, the chunks that matched as OpenAI sent them (each a Dict with "type" => "text" and "text"); raw holds the unparsed JSON item.

Request Type

UniLM.VectorStoreFileEntryType#
VectorStoreFileEntry(; file_id, attributes=nothing, chunking_strategy=nothing)

One file of a create_file_batch that carries its own attributes and chunking_strategy, sent as an entry of the batch's files. Its attributes are bounded as add_vector_store_file bounds them, else ArgumentError.

Result Types

UniLM.VectorStoreSuccessType#

Successful create/retrieve/update result wrapping a VectorStoreObject.

UniLM.VectorStoreListSuccessType#

Successful list_vector_stores result wrapping a VectorStoreList.

UniLM.VectorStoreFileSuccessType#

Successful add_vector_store_file, retrieve_vector_store_file or update_vector_store_file result wrapping a VectorStoreFileObject.

UniLM.VectorStoreFileListSuccessType#

Successful list_vector_store_files / list_file_batch_files result wrapping a VectorStoreFileList.

UniLM.VectorStoreContentSuccessType#

Successful vector_store_file_content result wrapping a VectorStoreFileContent.

UniLM.VectorStoreSearchSuccessType#

Successful search_vector_store result wrapping a VectorStoreSearchPage.

UniLM.VectorStoreBatchSuccessType#

Successful file-batch result wrapping a VectorStoreFileBatch.

UniLM.VectorStoreDeleteSuccessType#

Successful delete_vector_store or delete_vector_store_file result: the service confirmed (deleted is always true) the removal of id.

UniLM.VectorStoreFailureType#

Vector Stores API error result: HTTP status, the raw response body, and the request_id the service sent (x-request-id/request-id header), if any.

UniLM.VectorStoreCallErrorType#

Vector Stores API call that produced no usable reply (transport failure, timeout, or a 200 that could not be decoded); cause is the underlying exception — a UniLMTimeout for a timeout. last_observed is set only when poll_file_batch runs out of time or is cancelled: the last VectorStoreFileBatch it saw, if any.

UniLM.create_vector_storeFunction#
create_vector_store(; name=nothing, description=nothing, file_ids=nothing, expires_after=nothing,
                    chunking_strategy=nothing, metadata=nothing, service=OPENAIServiceEndpoint)

Create a vector store; description says what it is for. Returns VectorStoreSuccess, VectorStoreFailure, or VectorStoreCallError.

Pass config::Union{Nothing,RequestConfig} to override the timeout budget for this call (a single bounded attempt; max_attempts does not apply).

Pass cancel::Union{Nothing,CancelToken} (default: the ambient with_cancel token) to make the call cancellable: once the token is cancelled it returns a VectorStoreCallError whose cause is a UniLMCancelled — without sending anything when the token was already cancelled, at once when mid-request (never retried).

UniLM.search_vector_storeFunction#
search_vector_store(vector_store_id, query; max_num_results=nothing, rewrite_query=nothing,
                    filters=nothing, ranking_options=nothing, service=OPENAIServiceEndpoint)

Search a vector store for the chunks that match query, a string or a vector of strings, as the Responses file_search tool does: max_num_results (OpenAI's reference: 1 to 50, 10 by default), rewrite_query to let OpenAI rewrite the query for vector search, filters on the files' attributes (a comparison or compound filter Dict, as file_search takes) and ranking_options (Dict("ranker" => …, "score_threshold" => …)), each sent as given when set. Returns VectorStoreSearchSuccess, whose response is a VectorStoreSearchPage, VectorStoreFailure, or VectorStoreCallError.

Pass config::Union{Nothing,RequestConfig} to override the timeout budget for this call (a single bounded attempt; max_attempts does not apply).

Pass cancel::Union{Nothing,CancelToken} (default: the ambient with_cancel token) to make the call cancellable: once the token is cancelled it returns a VectorStoreCallError whose cause is a UniLMCancelled — without sending anything when the token was already cancelled, at once when mid-request (never retried).

UniLM.poll_file_batchFunction#
poll_file_batch(vector_store_id, batch_id; interval=2.0, timeout=300.0, service=OPENAIServiceEndpoint)

Poll a file batch until it reaches a terminal status (completed/failed/cancelled) and return that VectorStoreBatchSuccess. timeout bounds the wall-clock time of the whole poll (Inf waits indefinitely); interval is the pause between GETs. Both must be positive, else ArgumentError.

A transient failure — a status in the retryable set (408/429/500/502–504/520–524/529) or a GET that timed out — is polled through; any other failure is returned as it came. When the time runs out the result is a VectorStoreCallError with cause = UniLMTimeout(:deadline, …) and last_observed set to the last VectorStoreFileBatch seen (nothing if no GET succeeded).

Pass cancel::Union{Nothing,CancelToken} (default: the ambient with_cancel token) to make the poll cancellable: a cancel ends it at once, mid-GET or mid-pause, with a VectorStoreCallError whose cause is a UniLMCancelled and last_observed as above; a token cancelled before the poll sends nothing.

Pass config::Union{Nothing,RequestConfig} to bound each GET (a single attempt; its total_deadline is capped at the time left).

UniLM.cancel_file_batchFunction#
cancel_file_batch(vector_store_id, batch_id; service=OPENAIServiceEndpoint)

Cancel a file batch: OpenAI stops processing its files as soon as it can. Returns VectorStoreBatchSuccess with the batch as it then stands, VectorStoreFailure, or VectorStoreCallError; poll_file_batch waits for its final status.

Pass config::Union{Nothing,RequestConfig} to override the timeout budget for this call (a single bounded attempt; max_attempts does not apply).

Pass cancel::Union{Nothing,CancelToken} (default: the ambient with_cancel token) to make the call cancellable: once the token is cancelled it returns a VectorStoreCallError whose cause is a UniLMCancelled — without sending anything when the token was already cancelled, at once when mid-request (never retried).

UniLM.vector_store_idFunction#
vector_store_id(v::VectorStoreObject) -> String

Return the id of a VectorStoreObject, for use in file and batch calls.

Usage 

# Create a vector store, then add files already uploaded via the Files API
store = create_vector_store(name="docs", description="Product manuals")
store isa VectorStoreSuccess && println("Created: ", vector_store_id(store.response))
vs = vector_store_id(store.response)

# Add a single file with attributes a search can filter on, or a batch, then poll the batch
add_vector_store_file(vs, "file-abc123"; attributes=Dict("team" => "support", "year" => 2026))
batch = create_file_batch(vs, ["file-abc123", "file-def456"])
batch isa VectorStoreBatchSuccess && poll_file_batch(vs, batch.response.id)

# Search the store directly, keeping the chunks of files whose attribute matches
hits = search_vector_store(vs, "How do I reset the device?"; max_num_results=5,
                           filters=Dict("type" => "eq", "key" => "team", "value" => "support"))
hits isa VectorStoreSearchSuccess && [(h.filename, h.score) for h in hits.response.data]

# The store's files: list, read, update their attributes, detach
list_vector_store_files(vs; filter="completed")
vector_store_file_content(vs, "file-abc123")
update_vector_store_file(vs, "file-abc123", Dict("team" => "sales"))
delete_vector_store_file(vs, "file-abc123")

# List, retrieve, rename, delete
stores = list_vector_stores(limit=10, order="asc")
retrieve_vector_store(vs)
update_vector_store(vs; name="manuals")
delete_vector_store(vs)
