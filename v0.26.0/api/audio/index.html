API Reference

Audio API

Synthesize speech from text, transcribe audio to text, and translate speech into another language. speak runs on OpenAI's Realtime API or on Gemini TTS and returns 24 kHz, 16-bit mono audio, as a WAV file or as raw PCM. transcribe uploads an audio file to OpenAI and, with a local model that hears audio, to Ollama (Local Models with Ollama). translate streams a WAV file through an OpenAI Realtime translation session and returns the translated text.

Request Types

UniLM.SpeechRequestType#
SpeechRequest(; input, service=OPENAIServiceEndpoint, model=nothing, voice=nothing,
              response_format="wav", speed=nothing, instructions=nothing)

A text-to-speech request; pass it to speak. input is the text to read aloud. model and voice left nothing are the service's defaults:

servicespeaks throughdefault modeldefault voicevoicespeed
OPENAIServiceEndpointa Realtime API sessiongpt-realtime-2.1-minimarinalloy, ash, ballad, coral, echo, sage, shimmer, verse, marin, cedar0.25 to 1.5
GEMINIServiceEndpointGemini TTS (generateContent)gemini-3.8-flash-ttsKorethe 30 prebuilt voicesnone

Both services produce 16-bit mono PCM at 24 kHz: response_format "wav" returns it as a WAV file, "pcm" as the raw samples. instructions direct the delivery (tone, pace, accent): on OpenAI they follow the session's instruction to read input word for word, on Gemini they are the text's speech style (speechMetadata.style). Gemini TTS has no speed parameter: describe the pace in instructions ("speaking slowly").

Throws ArgumentError, before any request, for an empty input, a voice the service does not have, a response_format other than "wav" or "pcm", a speed out of range, and any speed on Gemini; and for GEMINIOpenAIServiceEndpoint, which has no speech route, naming GEMINIServiceEndpoint. Voices: OpenAI Realtime, Gemini TTS.

UniLM.TranscriptionRequestType#
TranscriptionRequest(; file, model=nothing, service=OPENAIServiceEndpoint)

An audio transcription request. file is a path on disk. model left nothing is the service's default: gpt-transcribe for OpenAI; Ollama has none, so a request to it names an installed model that hears audio (e.g. model="gemma4:e4b") or throws ArgumentError before any request. Optional languages, keywords, prompt, response_format, and temperature refine decoding. For gpt-transcribe, a legacy singular language is translated to languages. Other models retain their singular language field. Never set both forms. response_format is one of json, text, srt, verbose_json, vtt, diarized_json, and temperature lies in 0 … 1; anything else is an ArgumentError. On OpenAI, srt, vtt and verbose_json (subtitles and timestamps) are documented only for whisper-1, and diarized_json (speaker labels) only for gpt-4o-transcribe-diarize: deprecated models that shut down on February 26, 2027 (speech to text). Ollama's /v1/audio/transcriptions reads one language and the prompt, transcribes at temperature 0, and is asked for JSON only, the one form in which it reports a failure that arrives after its reply has begun (as text that failure reads as an empty transcript): a request to it that sets temperature, languages, keywords, or a response_format other than json throws ArgumentError before any request; read the text with transcript_text. Pass to transcribe.

Result Types

UniLM.SpeechSuccessType#

Successful speak result: audio holds a WAV file (content_type "audio/wav") or the raw 16-bit little-endian mono samples at 24 kHz ("audio/pcm"). Save it with save_audio.

UniLM.TranscriptionSuccessType#

Successful transcribe/translate result; text holds the transcript or translation (via transcript_text), raw the parsed JSON a transcription reply carried (nothing for a translation).

UniLM.AudioFailureType#

Audio error result: the HTTP status (nothing when a Realtime session reported the failure as an event, which carries no HTTP status), the raw response (the reply body, the Realtime event's JSON, or for a refused WebSocket upgrade HTTP.jl's report of its status) and the request_id the service sent (x-request-id/request-id header), if any.

UniLM.AudioCallErrorType#

Audio call that produced no usable reply (transport failure, timeout, cancel, a session that closed before its result, or a reply that could not be decoded); cause is the underlying exception — a UniLMTimeout for a timeout, a UniLMCancelled for a cancel, and, when the server closed a Realtime session, the HTTP.WebSockets.WebSocketError that carries its status and reason, which error names too.

Functions

UniLM.speakFunction#
speak(s::SpeechRequest; config=nothing) -> SpeechSuccess | AudioFailure | AudioCallError
speak(input; service=OPENAIServiceEndpoint, model=nothing, voice=nothing, response_format="wav",
      speed=nothing, instructions=nothing, config=nothing)

Synthesize speech from text; the keywords build a SpeechRequest.

On OPENAIServiceEndpoint the speech comes from a Realtime API session (wss://api.openai.com/v1/realtime, gpt-realtime-2.1-mini unless model names another), the replacement OpenAI names for its retiring text-to-speech models (text to speech): UniLM sets the voice, 24 kHz PCM output and instructions to read the text word for word, adds the text as a user message, asks for a response and collects its audio. Realtime models are conversational, and OpenAI notes that instructions are not guaranteed to be followed. On GEMINIServiceEndpoint it comes from Gemini TTS (generateContent on gemini-3.8-flash-tts unless model names another, speech generation), which reads the text verbatim.

Returns SpeechSuccess: a WAV file (response_format = "wav") or the raw samples ("pcm"). A failure the provider reports is an AudioFailure: an HTTP error status, a WebSocket upgrade the server refuses included (a bad key is a 401; response is then HTTP.jl's report of the status, since it does not keep the reply); a Gemini reply whose candidate did not finish (a finishReason other than STOP, such as MAX_TOKENS or SAFETY) or that has no candidate (a blocked prompt, its reason in promptFeedback), with status 200 and the reply as response; or on a Realtime session the error event, read even when the server closes the session while UniLM is still sending, or a response.done that did not complete (status is then nothing and response the event's JSON). A session that closes before its response is done (error names the close's status and reason, and cause is the close), a timeout, a cancel and a reply without usable audio are an AudioCallError. Audio received before a failure is never returned.

Pass config::Union{Nothing,RequestConfig} to bound the call (a single attempt; max_attempts does not apply). On OpenAI, total_deadline bounds the whole call whatever the socket does, connect_timeout the WebSocket open, and stream_idle_timeout every send and every wait for the next event; on Gemini it bounds the one HTTP request. Both observe the ambient CancelToken (with_cancel): a token already cancelled sends nothing, and a cancel ends the call at once, with an AudioCallError whose cause is a UniLMCancelled. Speech is not priced: token_usage and estimated_cost throw for a SpeechSuccess.

UniLM.transcribeFunction#
transcribe(t::TranscriptionRequest) / transcribe(path; model=nothing, kwargs...)

Transcribe audio to text in the source language. Returns TranscriptionSuccess (.text, via transcript_text), AudioFailure, or AudioCallError. model left nothing is the service's default (gpt-transcribe on OpenAI).

On Ollama, an installed model that hears audio transcribes through Ollama's OpenAI-compatible /v1/audio/transcriptions route. There is no default model, and what that route cannot carry — temperature, languages, keywords, a response_format other than json (text included: a failure after the reply has begun would read as an empty transcript) — throws ArgumentError before any request:

r = transcribe("memo.wav"; service=OllamaEndpoint(), model="gemma4:e4b", language="en")
r isa TranscriptionSuccess && println(transcript_text(r))

Pass config::Union{Nothing,RequestConfig} to override the timeout budget for this call (a single bounded attempt; max_attempts does not apply).

UniLM.translateFunction#
translate(path; language="en", model="gpt-realtime-translate", service=OPENAIServiceEndpoint,
          config=nothing) -> TranscriptionSuccess | AudioFailure | AudioCallError

Translate the speech in the WAV file at path into language and return the translation as text: a TranscriptionSuccess, read with transcript_text.

The audio goes to an OpenAI Realtime translation session (wss://api.openai.com/v1/realtime/translations, Realtime translation): UniLM sets the target language (the session's audio.output.language, such as "fr" or "es"; English unless named), streams the audio in 200 ms frames, closes the session and joins the translated transcript. The session also returns translated speech, which translate does not keep. Speech already in the target language can come back as empty text: an English clip translated into English did. A short clip's translation also varies from call to call: of ten translations into English of a two-second French sentence made with speak, one came back empty and six named words the sentence does not have (October 2026).

path must be a 16-bit PCM WAV file, at any sample rate and channel count: a translation session takes 24 kHz mono PCM16 only, so UniLM mixes the channels down and resamples by linear interpolation (speech-grade: there is no anti-aliasing filter). Any other file throws ArgumentError before any I/O, naming the conversion; so do an empty file, a blank language and a service without OpenAI's Realtime API.

A failure the provider reports is an AudioFailure: a Realtime error event, for example for a language it does not translate into (status = nothing, the event's JSON as response), read even when the server closes the session during the upload, or a WebSocket upgrade the server refuses (a bad key is a 401). A session that closes before session.closed (error names the close's status and reason), a timeout and a cancel are an AudioCallError. config::Union{Nothing,RequestConfig} bounds the call as for speak: total_deadline the whole call whatever the socket does, connect_timeout the open, stream_idle_timeout every send and every wait for the next event; a single attempt. The ambient CancelToken (with_cancel) is observed: a token already cancelled sends nothing, and a cancel ends the call at once, with an AudioCallError whose cause is a UniLMCancelled.

Accessors

UniLM.transcript_textFunction#
transcript_text(r::TranscriptionSuccess) -> String

The transcript text from a transcribe or translate result.

UniLM.save_audioFunction#
save_audio(r::SpeechSuccess, path) -> path

Write the synthesized audio bytes to path, atomically: the bytes go to a temporary file in the same directory, which is then renamed over path, so a failed write leaves any existing file intact. An existing file keeps its permission bits. A symlink is written through — a dangling one creates its target; a directory throws ArgumentError.

Usage 

# Speech from OpenAI (gpt-realtime-2.1-mini, voice "marin"), saved as a WAV file
r = speak("Hello from UniLM.")
r isa SpeechSuccess && save_audio(r, "hello.wav")

# Speech from Gemini TTS (gemini-3.8-flash-tts), another voice and a delivery, as raw PCM
r = speak("Hello from UniLM."; service=GEMINIServiceEndpoint, voice="Puck",
          instructions="warm and enthusiastic", response_format="pcm")

# Transcribe audio to text in its source language
t = transcribe("hello.wav"; languages=["en"], keywords=["UniLM", "Julia"])
t isa TranscriptionSuccess && println(transcript_text(t))

# Translate speech into French text (into English when no language is named)
t = translate("bonjour.wav"; language="fr")

# Transcribe on your own machine: Ollama, with an installed model that hears audio
t = transcribe("memo.wav"; service=OllamaEndpoint(), model="gemma4:e4b")

Translation

translate(path; language="en", model="gpt-realtime-translate") opens a Realtime translation session (wss://api.openai.com/v1/realtime/translations), sets the target language (audio.output.language), streams the audio in 200 ms frames, closes the session and joins the translated transcript into the text of a TranscriptionSuccess. The session also returns translated speech, which translate does not keep. Speech already in the target language can come back as empty text: an English clip translated into English did. A short clip's translation also varies from call to call: of ten translations into English of a two-second French sentence made with speak, one came back empty and six named words the sentence does not have (October 2026). A translation session takes 24 kHz mono 16-bit PCM only, so path must be a 16-bit PCM WAV file, at any sample rate and channel count: UniLM mixes the channels down and resamples by linear interpolation, which suits speech (there is no anti-aliasing filter). Any other file throws ArgumentError before any I/O, naming the conversion; convert it first, for example with ffmpeg -i in.m4a -c:a pcm_s16le out.wav. A language the session does not translate into is an AudioFailure carrying the provider's error event; the bounds and the cancellation are those of speech on OpenAI. Translation replaces OpenAI's file-upload translation endpoint, which shuts down on February 26, 2027 (Realtime translation).

Transcription

Transcription takes the service's default model when model is left nothing: gpt-transcribe on OpenAI. Its languages and keywords options are vectors of strings sent as repeated multipart fields. A singular language is translated to a one-element languages list for this model; older models keep their singular field. Setting both forms raises ArgumentError.

Ollama has no default: name a model that hears audio, such as gemma4:e4b. Its /v1/audio/transcriptions transcribes at temperature 0 and reads one language and a prompt, and UniLM asks it for JSON only, the one form in which Ollama reports a failure that arrives after its reply has begun, as an AudioCallError (by Ollama 0.40.6's source; untested here). response_format = "text" throws ArgumentError before the request — such a failure would read as an empty transcript — and so do temperature, languages, keywords and any other format: leave response_format unset and read the text with transcript_text. Ollama labels its replies application/x-ndjson, so they are read as JSON whatever the label. An endpoint declares transcription with the capability :transcription, which :audio implies.

OpenAI deprecated gpt-4o-transcribe, gpt-4o-mini-transcribe, gpt-4o-transcribe-diarize, and whisper-1 on August 26, 2026, with shutdown scheduled for February 26, 2027. The srt, vtt and verbose_json formats (subtitles and timestamps) are documented only for whisper-1, and diarized_json (speaker labels) only for gpt-4o-transcribe-diarize. OpenAI transcription guide, deprecation schedule.
