Gemini Context Caching & File Search

Two Gemini resources a request reads: a context cache, the start of a prompt stored ahead and named by a Chat's cached_content, and a File Search store, documents indexed for the Interactions API's file_search tool (gemini_file_search). Both are native Gemini only (GEMINIServiceEndpoint): the cache verbs check the :context_caching capability, the File Search verbs :file_search_stores, and any other endpoint throws ArgumentError before any request. How each is used and billed is on the Gemini pages: Context caching and File Search.

A resource is named as Gemini names it: "cachedContents/<id>", "fileSearchStores/<id>", "fileSearchStores/<store>/documents/<id>", and an operation's "fileSearchStores/<store>/operations/<id>" (an import's) or "fileSearchStores/<store>/upload/operations/<id>" (an upload's). A cache or a store verb takes the name or the id alone; a document or an operation verb takes the whole name. A name of another shape — an id with a /, an empty or dot segment — throws ArgumentError before any request. A reply without a field Gemini always sends is the verb's call error, never a result with the field made up.

UniLM.CacheObjectType#
CacheObject

A Gemini context cache, as create_cache, retrieve_cache, update_cache and list_caches return it; raw holds the cache as Gemini sent it.

  • name::String: "cachedContents/<id>", what a Chat's cached_content and the other cache verbs take (the verbs take the id alone too).
  • model::String: the model the cache was made for, without its models/ prefix: "Cached content can be only used with model it was created for".
  • display_name::Union{String,Nothing}: the name it was given; "" when none was.
  • total_tokens::Int: usageMetadata.totalTokenCount, the tokens the cache holds, which its storage bills.
  • create_time, update_time, expire_time (DateTime, UTC): when it was made, last updated, and expires; Gemini deletes it then.

A reply without one of these fields is no cache: the call returns its CacheCallError. The contents a cache holds are not returned: "It's not possible to retrieve or view cached content".

UniLM.CacheListType#
CacheList

A page of CacheObjects from list_caches; has_more signals a further page, which starts at raw["nextPageToken"], and raw holds the page as sent.

UniLM.CacheSuccessType#

Successful create_cache, retrieve_cache or update_cache result wrapping a CacheObject.

UniLM.CacheListSuccessType#

Successful list_caches result wrapping a CacheList.

UniLM.CacheDeleteSuccessType#

Successful delete_cache result: Gemini deleted the cache name (deleted is always true); its reply is empty, so name is the cache the call named.

UniLM.CacheFailureType#

Context caching error result: HTTP status, the raw response body, and the request_id the service sent, if any. A cache that is gone, or another project's, is Gemini's 403 "CachedContent not found (or permission denied)".

UniLM.CacheCallErrorType#

Context caching call that produced no usable reply (a missing key, transport failure, timeout, cancel, or a 200 that is not the documented cache); cause is the underlying exception — a UniLMTimeout for a timeout, a UniLMCancelled for a cancel.

UniLM.create_cacheFunction#
create_cache(chat::Chat; ttl=nothing, expire_time=nothing, display_name=nothing, config=nothing, cancel=nothing)

Cache the start of a prompt on Gemini (cachedContents.create): chat's system messages (the system instruction), its other messages (the contents, attachments included), its tools and tool_choice (the tool config), for chat.model. A request then names the cache with a Chat's cached_content — the result's name or the CacheObject itself — and holds only what follows: no system message, no tools, no tool_choice. Returns CacheSuccess, CacheFailure or CacheCallError.

  • ttl: the cache's lifetime in seconds; or expire_time, a UTC DateTime — one of them, else ArgumentError. Unset, Gemini keeps a cache for an hour.
  • display_name: at most 128 characters.

Throws ArgumentError before any request when chat.service lacks :context_caching (GEMINIServiceEndpoint has it), for a Gemini 4 model, which Google does not cache explicitly, and for a chat that sets a field a cache does not hold — max_tokens, reasoning_effort, stream, response_format, cached_content and the rest — which belong to the Chat that names the cache. Gemini refuses a cache below the model's minimum size (HTTP 400 "Cached content is too small. … mintotaltoken_count=1024" on gemini-3.8-flash, 2026-11-17).

A cache bills its storage by the hour (Context caching), which estimated_cost does not price; a reply that reads it bills the cached tokens at the model's cache-hit rate. config bounds the call (a single attempt: a create is never retried); cancel (default: the ambient with_cancel token) ends it with a UniLMCancelled in cause.

UniLM.retrieve_cacheFunction#
retrieve_cache(name; service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

A cache's metadata (cachedContents.get), by its name "cachedContents/<id>" or its id. Returns CacheSuccess, CacheFailure — a cache that expired or was deleted is Gemini's 403 — or CacheCallError. A malformed name throws ArgumentError before any request.

UniLM.list_cachesFunction#
list_caches(; limit=nothing, after=nothing, service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

A page of the project's caches (cachedContents.list): limit is the page size (pageSize; Gemini serves at most 1000, "values above 1000 will be coerced to 1000"), after the previous page's raw["nextPageToken"]. Returns CacheListSuccess, CacheFailure or CacheCallError. A limit below 1 throws ArgumentError before any request.

UniLM.update_cacheFunction#
update_cache(name; ttl=nothing, expire_time=nothing, service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

Move a cache's expiration (cachedContents.patch): a new ttl in seconds from now, or a new expire_time (UTC) — one of them, else ArgumentError before any request: "only expiration is updatable". Returns CacheSuccess with the updated cache, CacheFailure or CacheCallError.

UniLM.delete_cacheFunction#
delete_cache(name; service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

Delete a cache before it expires (cachedContents.delete), by its name or id. Returns CacheDeleteSuccess, CacheFailure or CacheCallError.

A document's settings, on an upload and an import alike: custom_metadata, at most 20 keys, each a string, a number or a vector of strings; max_tokens_per_chunk (1 to 512) and max_overlap_tokens (≥ 0), the white-space chunking. An upload also takes the document's display_name and mime_type.

UniLM.FileSearchStoreObjectType#
FileSearchStoreObject

A Gemini File Search store, as create_file_search_store, retrieve_file_search_store and list_file_search_stores return it; raw holds it as Gemini sent it.

  • name::String: "fileSearchStores/<id>", which gemini_file_search and the store verbs take (the verbs take the id alone too); Gemini derives the id from the display name.
  • display_name::Union{String,Nothing}; embedding_model::Union{String,Nothing}: the model that embeds its documents, without its models/ prefix ("gemini-embedding-001" unless the store was made with another).
  • active_documents, pending_documents, failed_documents (Int): its documents ready for retrieval, being processed, and failed; size_bytes::Int: the raw bytes ingested. Each is 0 when Gemini leaves it out, as it leaves out a zero.
  • create_time, update_time (DateTime, UTC).

A reply without a name, createTime or updateTime, or with a field of another JSON type, is no store: the call returns its FileSearchCallError.

UniLM.FileSearchDocumentObjectType#
FileSearchDocumentObject

A document in a File Search store, as retrieve_file_search_document and list_file_search_documents return it; raw holds it as Gemini sent it.

  • name::String: "fileSearchStores/<store>/documents/<id>", which the document verbs take.
  • display_name::Union{String,Nothing}; mime_type::Union{String,Nothing}; size_bytes::Int.
  • state::String: "STATE_PENDING" while its chunks are processed, "STATE_ACTIVE" when they are ready, "STATE_FAILED"; "STATE_UNSPECIFIED" when Gemini leaves it out.
  • custom_metadata::Dict{String,Any}: its custom metadata, each key's string, number or Vector{String} (Gemini's stringValue, numericValue, stringListValue).
  • create_time, update_time (DateTime, UTC).
UniLM.FileSearchOperationType#
FileSearchOperation

The long-running operation that puts a document into a store, as upload_to_file_search_store, import_to_file_search_store, retrieve_file_search_operation and poll_file_search_operation return it; raw holds it as Gemini sent it.

  • name::String: "fileSearchStores/<store>/operations/<id>" for an import, "fileSearchStores/<store>/upload/operations/<id>" for an upload.
  • done::Bool: false while the document is being processed (Gemini leaves done out until then).
  • document::Union{String,Nothing}: the name of the document it makes, once its reply names it — an upload's at once, an import's when done (an import's done reply gives the document's id alone, which is named in the operation's store).
  • error::Union{Dict{String,Any},Nothing}: the Status of an operation that failed (code, message).
UniLM.FileSearchStoreListType#
FileSearchStoreList

A page of FileSearchStoreObjects from list_file_search_stores; has_more signals a further page, which starts at raw["nextPageToken"].

UniLM.FileSearchDocumentListType#
FileSearchDocumentList

A page of FileSearchDocumentObjects from list_file_search_documents, oldest first; has_more signals a further page, which starts at raw["nextPageToken"].

UniLM.FileSearchStoreListSuccessType#

UniLM.FileSearchDocumentSuccessType#

UniLM.FileSearchDocumentListSuccessType#

UniLM.FileSearchOperationSuccessType#

Successful upload_to_file_search_store, import_to_file_search_store, retrieve_file_search_operation or poll_file_search_operation result wrapping a FileSearchOperation.

UniLM.FileSearchDeleteSuccessType#

Successful delete_file_search_store or delete_file_search_document result: Gemini deleted name (deleted is always true); its reply is empty, so name is the one the call named.

UniLM.FileSearchFailureType#

File Search error result: HTTP status, the raw response body, and the request_id the service sent, if any.

UniLM.FileSearchCallErrorType#

File Search call that produced no usable reply (a missing key, transport failure, timeout, cancel, or a 200 that is not the documented object); cause is the underlying exception. last_observed is set only when poll_file_search_operation runs out of time or is cancelled: the last FileSearchOperation it saw, if any.

UniLM.create_file_search_storeFunction#
create_file_search_store(; display_name=nothing, embedding_model=nothing, service=GEMINIServiceEndpoint,
                         config=nothing, cancel=nothing)

Create an empty File Search store (fileSearchStores.create). display_name (at most 512 characters) is the base of the store's name, which Gemini derives with a random suffix; embedding_model (e.g. "gemini-embedding-2", with or without its models/ prefix) embeds its documents, Gemini's default gemini-embedding-001 when unset. Returns FileSearchStoreSuccess, FileSearchFailure or FileSearchCallError.

A store keeps its documents "indefinitely until you manually delete" them; storing them is free, and indexing a document bills its embeddings at the embedding model's rate (File Search). Throws ArgumentError before any request when service lacks :file_search_stores or the display name is too long. config bounds the call (a single attempt); cancel (default: the ambient with_cancel token) ends it with a UniLMCancelled in cause.

UniLM.retrieve_file_search_storeFunction#
retrieve_file_search_store(name; service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

A File Search store (fileSearchStores.get), by its name "fileSearchStores/<id>" or its id: its document counts and size among it. Returns FileSearchStoreSuccess, FileSearchFailure (a store that does not exist is Gemini's 404) or FileSearchCallError.

UniLM.list_file_search_storesFunction#
list_file_search_stores(; limit=nothing, after=nothing, service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

A page of the project's File Search stores (fileSearchStores.list), oldest first: limit is the page size, 1 to 20 (else ArgumentError before any request; Gemini's default is 10), after the previous page's raw["nextPageToken"]. Returns FileSearchStoreListSuccess, FileSearchFailure or FileSearchCallError.

UniLM.delete_file_search_storeFunction#
delete_file_search_store(name; force=false, service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

Delete a File Search store (fileSearchStores.delete). A store that holds documents is deleted only with force=true, which deletes them too: without it Gemini answers HTTP 400 "Cannot delete non-empty FileSearchStore", a FileSearchFailure. Returns FileSearchDeleteSuccess, FileSearchFailure or FileSearchCallError.

UniLM.upload_to_file_search_storeFunction#
upload_to_file_search_store(store, path; display_name=nothing, mime_type=nothing, custom_metadata=nothing,
                            max_tokens_per_chunk=nothing, max_overlap_tokens=nothing,
                            service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

Upload the local file path into the File Search store store (its name or id) as a document (media.uploadToFileSearchStore), through Gemini's resumable upload: a start request with the document's settings, then the bytes. Gemini chunks, embeds and indexes it in a long-running operation: the result's FileSearchOperation names the document, and poll_file_search_operation waits for it to be done. Returns FileSearchOperationSuccess, FileSearchFailure or FileSearchCallError.

  • display_name: the document's display name; mime_type: the file's MIME type, else the one its extension gives the upload (and Gemini infers the document's).
  • custom_metadata: at most 20 key-value pairs, each value a string, a number or a vector of strings, which a search's metadata_filter reads (gemini_file_search).
  • max_tokens_per_chunk (1 to 512) and max_overlap_tokens (≥ 0): white-space chunking, Gemini's defaults when unset.

Throws ArgumentError before any request for a missing file, a file over 100 MB (Gemini's per-document limit), or a setting outside these bounds. Audio and video are not indexed ("Audio and video formats are not currently supported"). A start that names no session address is a FileSearchCallError. config bounds the call, both requests (a single attempt: an upload is never retried); cancel (default: the ambient with_cancel token) ends it with a UniLMCancelled in cause, and a token cancelled before the call reads no file.

UniLM.import_to_file_search_storeFunction#
import_to_file_search_store(store, file; custom_metadata=nothing, max_tokens_per_chunk=nothing,
                            max_overlap_tokens=nothing, service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

Import a file of Gemini's Files API (upload_file(path; service=GEMINIServiceEndpoint)) into the File Search store store as a document (fileSearchStores.importFile): file is its id or its name, "files/<id>". The settings are upload_to_file_search_store's. The document outlives the file, which Gemini deletes after 48 hours. Returns FileSearchOperationSuccess — the operation names its document once done (poll_file_search_operation) —, FileSearchFailure or FileSearchCallError.

UniLM.retrieve_file_search_operationFunction#
retrieve_file_search_operation(name; service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

The state of the operation that puts a document into a store (fileSearchStores.operations.get, and fileSearchStores.upload.operations.get for an upload's), by its whole name. Returns FileSearchOperationSuccess, FileSearchFailure or FileSearchCallError.

UniLM.poll_file_search_operationFunction#
poll_file_search_operation(name; interval=2.0, timeout=300.0, service=GEMINIServiceEndpoint, config=nothing,
                           cancel=nothing)

Read the operation name until it is done and return that FileSearchOperationSuccess: its document is ready, or its error says why not. timeout bounds the wall-clock time of the whole poll (Inf waits indefinitely), interval is the pause between reads; both must be positive, else ArgumentError. A transient failure (a retryable status, a read that timed out) is polled through; any other is returned as it came. When the time runs out, or cancel (default: the ambient with_cancel token) is cancelled, the result is a FileSearchCallError whose cause is the UniLMTimeout or UniLMCancelled and whose last_observed is the last operation seen. config bounds each read.

UniLM.list_file_search_documentsFunction#
list_file_search_documents(store; limit=nothing, after=nothing, service=GEMINIServiceEndpoint, config=nothing,
                           cancel=nothing)

A page of the documents in a File Search store (fileSearchStores.documents.list), oldest first: store is its name or id, limit the page size, 1 to 20 (else ArgumentError before any request; Gemini's default is 10), after the previous page's raw["nextPageToken"]. Returns FileSearchDocumentListSuccess, FileSearchFailure or FileSearchCallError.

UniLM.retrieve_file_search_documentFunction#
retrieve_file_search_document(name; service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

A document of a File Search store (fileSearchStores.documents.get), by its whole name, "fileSearchStores/<store>/documents/<id>". Returns FileSearchDocumentSuccess, FileSearchFailure (a document that does not exist is Gemini's 404) or FileSearchCallError.

UniLM.delete_file_search_documentFunction#
delete_file_search_document(name; force=true, service=GEMINIServiceEndpoint, config=nothing, cancel=nothing)

Delete a document from its File Search store (fileSearchStores.documents.delete), by its whole name. A document's chunks are its indexed content, and Gemini deletes a document that has chunks only with force — every indexed document has them: without it the API answered HTTP 400 "Cannot delete non-empty Document" — so force is true unless set false. Returns FileSearchDeleteSuccess, FileSearchFailure or FileSearchCallError.

Usage 

using UniLM, Dates

# A cache of a long document, for gemini-3.8-flash, kept ten minutes.
doc = read("handbook.txt", String)
base = Chat(service=GEMINIServiceEndpoint, model="gemini-3.8-flash",
            messages=[Message(Val(:system), "Answer from the handbook."), Message(Val(:user), doc)])
made = create_cache(base; ttl=600, display_name="handbook")
cache = made.response                       # a CacheObject: name, total_tokens, expire_time
chat = Chat(service=GEMINIServiceEndpoint, model="gemini-3.8-flash", cached_content=cache,
            messages=[Message(Val(:user), "How many days of leave?")])
r = chatrequest!(chat)                      # r.usage.cached_tokens: the cache's tokens, at the cache-hit rate
update_cache(cache.name; ttl=1800)          # half an hour more
delete_cache(cache.name)

# A File Search store with one document, searched through the Interactions API.
store = create_file_search_store(; display_name="handbook").response
op = upload_to_file_search_store(store.name, "handbook.pdf"; custom_metadata=Dict("year" => 2026)).response
done = poll_file_search_operation(op.name)
done isa FileSearchOperationSuccess && isnothing(done.response.error)
r = respond("How many days of leave?"; service=GEMINIServiceEndpoint, model="gemini-3.8-flash",
            tools=[gemini_file_search(store.name; metadata_filter="year = 2026")])
delete_file_search_store(store.name; force=true)
