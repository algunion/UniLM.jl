Reference · API: OpenAI platform

Webhooks API

Verify inbound webhook signatures (Standard Webhooks / HMAC-SHA256) and parse events into typed values. This is an inbound utility with no provider endpoint — HMAC is built on the SHA standard library. OpenAI webhooks.

Types and Constants

UniLM.WebhookEventType#
WebhookEvent

A parsed webhook event from parse_webhook: id, type, and created_at; data holds the event payload and raw the unparsed JSON response.

UniLM.WEBHOOK_EVENTSConstant#

The event types of OpenAI's webhooks (reference): background responses, batches and fine-tuning jobs that end, incoming SIP calls for the Realtime and Live APIs, safety warnings and deactivations for a safety identifier, and safety alerts. live.call.incoming is deprecated in favour of live.transport.incoming and retained for existing subscriptions. The reference also lists eval.run.succeeded, eval.run.failed and eval.run.canceled, which OpenAI sends until its Evals API shuts down on November 30, 2026 (deprecations): they are left out, so a filter on this list drops them.

Functions

UniLM.verify_webhookFunction#
verify_webhook(payload::AbstractString, headers, secret::AbstractString; tolerance_seconds=300) -> Bool

Verify an OpenAI webhook signature (Standard Webhooks). payload is the raw request body; headers is a Dict or iterable of pairs containing webhook-id, webhook-timestamp, and webhook-signature; secret is the endpoint signing secret, with or without the whsec_ prefix: without it, the secret is read as base64 too, as the Standard Webhooks libraries read it (OpenAI's SDKs take an unprefixed secret's raw bytes as the key). Returns true iff a fresh, validly-signed v1 signature is present.

Replay protection: timestamps outside ±tolerance_seconds of now are rejected, as are timestamps that are not finite numbers — pass tolerance_seconds=Inf to skip the time check (e.g. when replaying a stored fixture). Uses a constant-time digest compare. Negative or NaN tolerances throw ArgumentError.

Whitespace around secret is ignored. Throws ArgumentError before any check when the rest is empty ("", whitespace, or whsec_ alone): anyone can sign with an empty key, so under one a forged delivery would verify. Throws ArgumentError when the rest is not valid base64 — a character outside A-Z, a-z, 0-9, + and / (whitespace inside it included), or = padding anywhere but at its end or more than its last group lacks — for a delivery that reaches the signature check: that is a misconfiguration of this endpoint, and reporting it as an unverified signature would silently drop every webhook. A false return therefore always means the message failed verification.

UniLM.parse_webhookFunction#
parse_webhook(payload::AbstractString) -> WebhookEvent

Parse a webhook JSON payload into a typed WebhookEvent. Verify the signature with verify_webhook first.

Usage 

# Verify an inbound webhook, then parse it into a typed event
if verify_webhook(payload, headers, ENV["OPENAI_WEBHOOK_SECRET"])
    event = parse_webhook(payload)
    event.type in WEBHOOK_EVENTS && println("Event: ", event.type, " (", event.id, ")")
end

WEBHOOK_EVENTS leaves out the eval.run.* events, which OpenAI sends until its Evals API shuts down on November 30, 2026: the filter above drops them, so match event.type yourself if you still run evals.
