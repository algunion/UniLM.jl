Introduction

Install

Add the package

UniLM requires Julia 1.13 or later and is registered in Julia's General registry:

using Pkg
Pkg.add("UniLM")

Or from the Pkg REPL:

pkg> add UniLM

To track the latest unreleased changes, install from GitHub instead:

Pkg.add(url="https://github.com/algunion/UniLM.jl")

Set up your provider

A hosted provider reads its API key from an environment variable; set it in the environment Julia starts from, for example:

export OPENAI_API_KEY="sk-..."

A model you run yourself — through Ollama, vLLM, LM Studio or llama.cpp — needs no key unless its server was started with one: the setup is where the server listens. Each provider's Setup section names what it reads and where its requests go; the provider's name below opens it.

Handle the result

A request to a model returns its outcome as a typed result rather than throwing it: a success holding the reply, a failure holding what the provider answered with, or a call error holding what ended the call; nl_classify, nl_dispatch and @branch, which turn a decision into a key or a method, throw a SystemOneError for a failed call instead, and, with no fallback or _ line, a LowConfidenceError or DecisionDeclinedError for an answer they cannot act on. Results shows the types each verb returns and how to read them; four of the Responses lifecycle verbs — delete_response, list_input_items, compact_response and count_input_tokens — return the provider's answer as a Dict on success.
