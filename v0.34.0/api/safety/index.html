Reference · API: OpenAI platform

Safety & Provenance API

Read the safety case behind a safety.warning_issued or safety.deactivation_issued webhook and the project safety alert behind a safety.alert.created one (the :safety capability), and check an image, audio or PDF file for OpenAI's provenance signals (:content_provenance): "Images: PNG, JPEG, WebP, and GIF. Audio: MP3, Opus, AAC, FLAC, WAV, and PCM. Documents: PDF." (content provenance). OpenAI only.

Objects

UniLM.SafetyCaseType#
SafetyCase

A safety case, the record behind a safety.warning_issued or safety.deactivation_issued webhook: its id, created_at (Unix seconds), the entity_identifier it concerns (a safety_identifier your requests sent), its reason (nothing when OpenAI gives none) and the notice it issued, "warning" or "deactivation". raw holds the reply.

UniLM.SafetyAlertType#
SafetyAlert

A project safety alert, the record behind a safety.alert.created webhook: its id, created_at (Unix seconds), the request_id, response_id and model of the request it concerns, request_paused (whether OpenAI registered the block; it does not confirm that the response stopped), the error_type ("potentially_unintended_data_transfer", "potentially_unintended_data_access", "potentially_unintended_destructive_activity" or "other") and its reason, nothing for a zero-data-retention request. raw holds the reply.

UniLM.ProvenanceCheckType#
ProvenanceCheck

The result of check_content_provenance: created_at (Unix seconds) and the ProvenanceResults that apply to the file. raw holds the reply.

UniLM.ProvenanceResultType#
ProvenanceResult

One provenance signal of a ProvenanceCheck: its type, "c2pa" (C2PA Content Credentials) or "synthid" (a SynthID watermark); its outcome, "detected" or "not_detected"; for C2PA, the manifest's validation_state ("trusted", "valid", "invalid" or "not_present") and issuer; the OpenAI model and the generated_at time (RFC 3339) the signal records, when it records them. A field the signal does not have is nothing.

Result Types

UniLM.SafetyCaseSuccessType#

Successful retrieve_safety_case result wrapping a SafetyCase.

UniLM.SafetyAlertSuccessType#

Successful retrieve_safety_alert result wrapping a SafetyAlert.

UniLM.ProvenanceCheckSuccessType#

Successful check_content_provenance result wrapping a ProvenanceCheck.

UniLM.SafetyFailureType#

Safety or content provenance API error result: HTTP status, the raw response body, and the request_id the service sent (x-request-id/request-id header), if any.

UniLM.SafetyCallErrorType#

Safety or content provenance API call that produced no usable reply (transport failure, timeout, or a 200 that could not be decoded); cause is the underlying exception — a UniLMTimeout for a timeout.

Request Functions

UniLM.retrieve_safety_caseFunction#
retrieve_safety_case(id; service=OPENAIServiceEndpoint)

The safety case id (a safety.warning_issued or safety.deactivation_issued webhook's data["id"]) as a SafetyCaseSuccess; a case that does not exist, or that the key may not read, is OpenAI's 404, and a key without the api.safety.read scope gets its 403 (witnessed on November 16, 2026): each a SafetyFailure.

Each safety and provenance verb makes one attempt bounded by its config and takes cancel: a cancelled token returns a SafetyCallError whose cause is a UniLMCancelled, without sending anything when it was cancelled before the call.

UniLM.retrieve_safety_alertFunction#
retrieve_safety_alert(id; service=OPENAIServiceEndpoint)

The project safety alert id (a safety.alert.created webhook's data["id"]) as a SafetyAlertSuccess; an alert of another project, or none, is OpenAI's 404, a SafetyFailure.

UniLM.check_content_provenanceFunction#
check_content_provenance(path; mime_type=<from the extension>, service=OPENAIServiceEndpoint)

Check the image, audio or PDF file at path for OpenAI's provenance signals: a ProvenanceCheckSuccess holding a ProvenanceResult per signal that applies to the file. The content provenance guide lists the formats: "Images: PNG, JPEG, WebP, and GIF. Audio: MP3, Opus, AAC, FLAC, WAV, and PCM. Documents: PDF." (OpenAI's API specification names image and audio files only). The file goes as the one multipart part file, whose own Content-Type is mime_type: by default the one its extension names, as upload_file sends it; pass it for an extension that names none, such as .opus or .aac. A path that is no file is an ArgumentError.

"not_detected" means the check found no supported signal: the file may still come from OpenAI, its metadata stripped or its watermark degraded, or from another company's model, which the check does not detect (content provenance).

Usage 

# The record behind a verified safety webhook
event = parse_webhook(payload)
if event.type == "safety.alert.created"
    alert = retrieve_safety_alert(event.data["id"])
    alert isa SafetyAlertSuccess && println(alert.response.error_type, ": ", alert.response.response_id)
elseif event.type in ("safety.warning_issued", "safety.deactivation_issued")
    case = retrieve_safety_case(event.data["id"])
    case isa SafetyCaseSuccess && println(case.response.notice, " for ", case.response.entity_identifier)
end

# Provenance signals of an image
check = check_content_provenance("generated.png")
check isa ProvenanceCheckSuccess && [(r.type, r.outcome) for r in check.response.results]
